## New
- **Much shorter loading times.** Measured on a real Vita, entering a battle drops from about 4.5 seconds to 2.8 seconds the first time and 2 seconds after that. Opening the field menu drops from 1.4 to under 1 second, and closing it from 2 to 1.4 seconds.
- The game now reads `main.obb` directly, unpacks its files about twice as fast, and keeps recently used files in 64 MB of memory, so menus and later battles barely touch the memory card.
- The game now refuses a `main.obb` of the wrong size at startup, for example an incomplete copy.

## Other changes
- First stable **v1.0.0** release. The timings come from one save on a real Vita using a measurement build, so yours may differ a little. A complete playthrough on real hardware has not been done.
- Advanced settings in `options.cfg` turn each improvement off if you ever need to: `obbreader=0`, `fastgzip=0` and `assetcache=0`.
- Install **FF6.vpk** and provide your own Android **2.1.6 or 2.1.7** `libFF6.so` and matching `main.obb`. See the [README](https://github.com/frangarcj/ff6_vita#installation) for setup instructions. Existing saves do not need to be deleted.
