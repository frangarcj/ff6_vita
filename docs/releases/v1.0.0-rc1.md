## First public release candidate

This is **v1.0.0-rc1**, the first public GitHub candidate of the original
Android Final Fantasy VI port for PS Vita. Development reports labelled local
RC1/RC2 are earlier private test snapshots, not previous public releases.
This is a **prerelease**, not a full-game or hardware certification.

### LiveArea artwork refresh

This RC1 has been repackaged in place with the LiveArea assets and layout
provided by **Standard-Republic**. Thank you! The refresh includes the icon,
background, transparent startup image, **Configuration** button and `pic0.png`.
The button opens the bundled Configurator; the template no longer has a
placeholder target. The startup image has been converted to indexed PNG8
without resizing, and all other supplied images are unchanged.

The release URL and version remain **v1.0.0-rc1**. Download the refreshed VPK
and its matching checksums/manifest/symbols rather than mixing old and new
downloads. This changes presentation assets, packaging validation and the
authorized repack workflow, not gameplay, saved data or default options.
Install the updated VPK normally; do not delete your `ux0:data/ff6` directory.

### Features and fixes

- LiveArea **Configurator** for graphics, language, audio and controls, with
  Save/Launch/Discard actions and START to save and launch. Configuration saving
  preserves unknown options/comments and reports failures without truncating
  the previous file.
- Cross/Circle confirmation swap, selectable output resolution with native
  fallback, and optional presentation aspect ratios for the fixed 2D view.
- Seven optional PostFX effects adapted from FF3 Vita: Negative, FXAA, Sepia,
  Greyscale, CRT, CRT-Bleeding and CRT-Bleeding-Flat.
- Sharp-bilinear final world scaling, corrected battle-menu clipping, properly
  aligned text, complete glyph-edge rasterization and cleared reused atlas cells.
- In-place texture updates, palette expansion and guarded fixed-point colour
  conversion retained from the FF6 graphics work.
- Release builds exclude diagnostic logs/triggers, artificial 15-second pauses,
  pixel-readback probes and overlay experiments.
- Automated sanitizer regressions, VitaSDK builds, package validation, matching
  crash-report symbols and SHA-256 provenance records.

### Installation

Install **FF6.vpk** and provide the original legally obtained Android **2.1.6**
ARMv7 `libFF6.so` and its matching OBB as:

```text
ux0:data/ff6/libFF6.so
ux0:data/ff6/main.obb
```

The VPK contains the loader, Configurator, fonts, shaders and LiveArea resources,
**not** the commercial executable, APK, OBB or saved games. Follow the README for
kubridge, the shader compiler, compatible file checksums and installation notes.
Back up existing `RockDat*.sav` files before testing. No save/config deletion is
needed to install this package.

The baseline remains native 544p / 3:2. To use the menu-tested upscale, enable
**Sharp-bilinear final scale** and keep **Font scale = 100**. PostFX, alternative
aspect ratios and higher output resolutions are opt-in. Aspect modes stretch
the existing game area; unlike FF3's 3D camera, they do not reveal more scenery.

### Known limitations / test requests

- Real Vita/PSTV acceptance, sustained play and suspend/resume remain open.
- Normal save and quicksave workflows need full exit/relaunch/load validation.
- Higher resolutions and optional effects need hardware performance checks.
- Broader menus/dialogue/languages and first/repeated Fire Beam effects still
  need testing in the final build. Thai font coverage is incomplete.
- Thin tile seams and the separately filtered full-string text path remain
  documented limitations. Google Play cloud saves/achievements are unavailable.

### Download contents

**FF6.vpk** is the installable package. **FF6.elf** and **companion.elf** are
matching unstripped symbols for crash investigation, not extra files to install.
**manifest.json** records build/source/dependency identities; **SHA256SUMS**
verifies all downloaded files. Keep the matching symbols with any bug report.
