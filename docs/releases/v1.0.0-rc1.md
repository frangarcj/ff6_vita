## New features
- **Configurator:** change graphics, language, sound and controls directly from LiveArea.
- **Display options:** sharp-bilinear scaling, resolution and aspect ratio settings, Cross/Circle swap and seven PostFX effects, including FXAA and CRT.
- **LiveArea artwork:** new icon, backgrounds and Configuration button by **Standard-Republic**. Thank you!

## Fixes
- Improved menu fonts, missing glyphs and vertical text alignment.
- Fixed clipped battle commands with sharp-bilinear enabled.
- Improved texture updates and removed the old Debug pause during battle effects.

## Other changes
- First public **v1.0.0-rc1** prerelease. Vita/PSTV and save/load testing are still in progress.
- Install **FF6.vpk** and provide your own Android **2.1.6** `libFF6.so` and matching `main.obb`. See the [README](https://github.com/frangarcj/ff6_vita#installation) for setup instructions. Existing saves do not need to be deleted.
