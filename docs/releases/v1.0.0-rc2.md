## Fixes
- Fixed a crash on the title screen after opening the "?" help icon: the Java global-reference calls the game makes when it closes the help were not implemented. Reported in #1.
- **Sharp-bilinear is now on by default**, which removes the thin seams between tiles. Existing installs keep their saved setting; turn it on in the Configurator.

## Other changes
- Second public **v1.0.0-rc2** prerelease. Vita/PSTV and save/load testing are still in progress.
- Install **FF6.vpk** and provide your own Android **2.1.6** `libFF6.so` and matching `main.obb`. See the [README](https://github.com/frangarcj/ff6_vita#installation) for setup instructions. Existing saves do not need to be deleted.
