## Fixes
- Fixed the music and sound effects playing too fast and too high: the audio port now runs at 32000 Hz, the rate the game's mixer produces, instead of 44100 Hz.

## Other changes
- Third public **v1.0.0-rc3** prerelease. The audio rate change has been checked in the Vita3K emulator only; testing on a real Vita/PSTV is still in progress.
- Install **FF6.vpk** and provide your own Android **2.1.6** `libFF6.so` and matching `main.obb`. See the [README](https://github.com/frangarcj/ff6_vita#installation) for setup instructions. Existing saves do not need to be deleted.
