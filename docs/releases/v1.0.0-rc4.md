## New
- **Android 2.1.7 support.** The port now accepts both the **2.1.6** and **2.1.7** `libFF6.so`, and tells them apart by size and checksum. Both Android releases use the **same `main.obb`**, so either APK works with the OBB you already have.
- With 2.1.7 the game keeps its original 3:2 view (816x544 on the Vita) instead of its new 10% horizontal stretch. The decorative side frames are optional: copy the APK's `assets/` folder to `ux0:data/ff6/assets/` to see them.

## Other changes
- Fourth public **v1.0.0-rc4** prerelease. Both executables have been checked in the Vita3K emulator only (title screen and a field scene); battles, menus, audio and testing on a real Vita/PSTV are still in progress.
- With 2.1.7 the online news, WebView, achievements and Google sign-in do nothing.
- Install **FF6.vpk** and provide your own Android **2.1.6 or 2.1.7** `libFF6.so` and matching `main.obb`. See the [README](https://github.com/frangarcj/ff6_vita#installation) for setup instructions. Existing saves do not need to be deleted.
